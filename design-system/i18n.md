# Copy / i18n

Extractor’s dashboard is **English-first**. There is no catalog runtime yet.

## Rules

- Do not hardcode Portuguese (or any other locale) into templates.
- Dynamic values (`job.display_title`, `job.error`, log text) are fine in Jinja; the engine auto-escapes.
- When adding several new user-facing strings, put them in a dict (template context or a `STRINGS` map) rather than scattering one-off literals that will be painful to translate later.
- Placeholder and “coming soon” copy counts as user-facing.
- Brand mark letters (`PA`) stay in markup.

## Status labels

Jobs list keeps API status values (`queued`, `running`, `done`, `failed`) as the pill text. Job detail uses the friendly map in `app/progress.py` (`Waiting`, `Working`, `Ready`, `Failed`). Visual tone is still the CSS pill class.

Pipeline step titles/details also live in `app/progress.py` (`STEPS`) so copy stays in one place.
